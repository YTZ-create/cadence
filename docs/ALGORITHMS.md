# 算法口径（v2.0）

本文只描述当前仓库中的可复核算法，不包含任何真实个人数据。所有分数均为个人参考，不是医学指标。

## 1. 数据流

```text
手表 BLE
  → bridge.py（只读设备数据）
  → parse_data.py（帧解析）
  → data/health/watch/DATE.json（原始归档）
  → watch_health.py（同步/归档/报告）
  → sleep_store.py（睡眠账本）
  → recovery_score.py（恢复分）
  → energy_score.py（精力分 / 高能时段）
```

反应力测试走独立链路：

```text
reaction_test.py（桌面测试）
  → data/health/reaction/DATE.json + log.jsonl
  → energy_score.py 的 rt_* 特征
```

## 2. 睡眠账本

- 记录按**醒来那天**归属日期；
- 时长只记夜间睡眠，不把小睡并入；
- 动态目标在历史满 14 天后启用，目标锁 7–9 小时；
- 单日睡眠债按 ±4 小时封顶；
- 对外的“近两周债”使用 14 天滚动窗口；
- 质量分 = 时长达标 50% + 深睡占比 25% + 规律性 25%（缺项归一化）。

## 3. 恢复分

分项与权重（合计 100）：

| 分项 | 权重 | 口径 |
|---|---:|---|
| 睡眠时长达成 | 30 | 固定绝对 |
| 连续性/睡眠效率 | 15 | 固定绝对 |
| 深睡占比 | 15 | 个人百分位 |
| HR dip | 20 | 个人百分位 |
| 阶段心率梯度 | 5 | 个人百分位 |
| 血氧 | 10 | 固定安全阈值 |
| 压力 | 5 | 个人百分位（反向） |

### 固定绝对项

- 时长：`100 × duration_min / target_min`，钳制 0–100；
- 连续性：按睡眠效率 95%/90%/85%/80% 分档，夜醒额外扣分；
- 血氧：取睡眠窗口内**最低 3 点的中位数**，不用单点最小值；低于 90% 明显降分。

### 个人百分位项

深睡、HR dip、阶段梯度、压力在个人基线满 14 晚后使用百分位：

```text
0%   → 20
5%   → 40
25%  → 60
50%  → 75
75%  → 90
95%  → 100
100% → 100
```

- 压力方向反转（越低越好）；
- 基线不足 14 晚时退回固定参考公式；
- 中位数对应 75 分，避免“个人正常 = 50 分”的系统性压低。

### 缺失、置信度与样本门槛

- 缺失项按剩余权重重归一，并记录 `missing` 与 `weight_coverage`；
- 置信度“高”要求：权重覆盖率 ≥85%、实际 HR dip 存在、个人项已启用、基线满 14 晚；
- 睡眠心率 ≥10 条、深睡/浅睡阶段心率各 ≥3 条、SpO2 ≥3 点、压力 ≥3 点；
- 不足门槛即视为缺项，不硬凑。

## 4. 精力分

### 校准期

```text
精力分 = 恢复分 - 近 7 天睡眠债变差惩罚
```

- 债变差惩罚 = `min(4, 新增欠债分钟 / 60 × 0.5)`；
- 债稳定或改善不扣分；
- **自评和 events 不参与当天分数**，只作为个人模型训练标签；
- 个人模型特征不包含 `prev_rating`，避免把昨天的自评当输入。

### 个人模型

- 至少 45 天配对数据才可试训；
- 满 60 天且后 20% 时间外验证 MAE ≤10、优于“照抄昨天”至少 1 分才启用；
- 特征包括睡眠恢复、深睡、心率、血氧、压力、周几、反应力等；
- 未通过验证则继续使用校准期公式。

## 5. 高能时段

### 当前：校准期模板

- 主窗口：起床后 90 分钟起，基础 120 分钟；
- 下午窗口：15:30 起，基础 120 分钟；
- 最近 7 天睡眠债恶化 ≥2 小时：主窗口缩至 90 分钟，总时长 3小时30分钟；
- 债稳定/改善：主窗口 120 分钟，总时长 4小时；
- 个人模型激活后仍回退模板，`high_energy_source=template`，不会因模型启用而消失。

### 未来：日内曲线

模板是校准期主输出 + 长期 fallback。切换为 `curve` 必须同时满足：

1. events 覆盖一天多个时段且跨多天；
2. 日内曲线在时间外验证中优于模板，验证指标事先确定；
3. 数据不足或模型异常时可回退模板。

不得用“恢复分越高加半小时”这类临时公式替代曲线。

## 6. 反应力特征

日报聚合字段：

- `median_ms`：当天各次测试中位数的中位数（每次测试等权）；
- `lapses_total`：当天漏拍总数；
- `false_starts_total`：当天误点总数；
- `time_since_wake_min`：当天测试距起床分钟中位数；
- `skipped`：被跳过的坏记录数。

训练特征：

| 特征 | 含义 |
|---|---|
| `rt_median` | 当天反应中位数 |
| `rt_lapses` | 当天漏拍总数 |
| `rt_false_starts` | 当天误点总数 |
| `rt_time_since_wake` | 距起床分钟中位数 |
| `rt_missing` | 当天没有可用测试 = 1 |

没有测试时其余反应特征为空，并保留 `rt_missing`，避免把缺失误当成中位数。

## 7. 验证边界

- 这些算法来自个人纵向使用，不是经过临床验证的模型；
- 恢复分/精力分/高能时段均为个人参考；
- 手表睡眠阶段、深睡时长是设备估算；
- 高能时段模板尚未用足够时间标签验证；
- 个人模型尚未在本仓库附带个人数据上训练。
